# NestWorth UX Prototype 🏠

An interactive UX/UI prototype showcasing design concepts and features for the NestWorth budgeting application.

## 🎨 About This Prototype

This is a **non-functional design showcase** - think of it as a LEGO instruction manual showing what's possible! It demonstrates various UI components, visualizations, and interaction patterns that could be implemented in the actual NestWorth application.

## ✨ Featured Pages

- **🏠 Dashboard** - Combined overview with current status and forecasts
- **🧾 Transactions** - Multi-line cash flow visualization (Income, Spending, Investment) with smart filters
- **💰 Savings Funds** - Goal tracking with progress indicators and balance history
- **💵 Cash on Hand** - Financial health visualization with trend analysis
- **💰 Budget** - Monthly budget tracking with visual indicators
- **🔮 Forecasting** - Interactive scenario planning with adjustable sliders for income, expenses, and investments
- **📊 Balance History** - Historical trends (placeholder)

## 🚀 Live Demo

Deploy this app to Streamlit Cloud: [streamlit.io/cloud](https://streamlit.io/cloud)

## 💡 Purpose

This prototype showcases:
- Data visualization techniques (line charts, pie charts, bar charts, area charts)
- Interactive controls and filters (dropdowns, multi-select, sliders)
- Forecasting interfaces with confidence ranges
- Scenario planning tools with real-time impact visualization
- Budget management layouts with progress indicators
- User-friendly navigation patterns

## 🛠️ Built With

- **Streamlit** - Interactive web app framework
- **Plotly** - Dynamic charts and visualizations
- **Pandas** - Data manipulation

## 📦 Local Setup

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/nestworth-prototype.git
cd nestworth-prototype

# Install dependencies
pip install -r requirements.txt

# Run the app
streamlit run app.py
```

The app will open at `http://localhost:8501`

## 📋 Files Needed for Deployment

- `app.py` - Main application file
- `requirements.txt` - Python dependencies
- `README.md` - This file
- `.gitignore` - Git ignore rules
